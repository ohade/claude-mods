## Fallbacks that ended with this step

Ohad accepted three on 2026-11-11:

1. The module's open-question block when the published snapshot is stale or failed, or the session id
   does not match. Such a turn now ends without a block.
2. The module's local block for an uncovered input when its claim helper failed. The command hook
   prints "unavailable" to stderr and lets Stop through.
3. The 2-second wait at Stop for a classifier label in flight. A prompt labelled a question late is
   blocked one turn later.

The refuter review found a fourth, which the brief did not name. It is of the same kind as the first,
for the other two block types:

4. At Stop the module republished the snapshot and then claimed freshness kinds and uncovered inputs
   itself. It could therefore still block when the command hook had read an older snapshot, for
   example after a failed publish that followed an edit. Such a turn now ends without a block. Every
   mutation tool, label and response capture republishes the snapshot, so the gap is a failed or stale
   publish only. Status on 2026-11-11: waiting for Ohad's confirmation before this step lands.
